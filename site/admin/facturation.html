Facturation

Exporter les commandes pour la comptabilité

Le fichier se télécharge sur votre ordinateur. Dans Google Sheets, ouvrez-le par Fichier > Importer. Dans Excel, un double clic suffit.

Les dates portent sur le paiement, pas sur la date de commande. C'est l'encaissement qui compte pour la déclaration. Laissez vide pour tout prendre.

Une facture est émise automatiquement dès qu'une commande est réglée. Elle ne se supprime ni ne se modifie : en cas d'annulation ou de rétractation, on émet un avoir, qui l'annule sans l'effacer. Le remboursement, lui, se fait dans Stripe.
